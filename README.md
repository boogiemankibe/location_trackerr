# 📍 Location Tracker

> *A high-precision geolocation tool built with the Flask framework.*

This application captures the **precise location** of a target user the moment a specific button is clicked. It is designed for seamless tracking and easy data management through a dedicated administrative interface.

---

## 🚀 Live Demo

You can access the live application and its components using the links below:

*   **Main Application:** [Jumia Rewards Portal](https://jumia-rewards-portal.onrender.com/)
*   **Admin Dashboard:** [View Results (Admin Only)](https://jumia-rewards-portal.onrender.com/view_results_admin_9988)

## ✨ Key Features

*   **One-Click Tracking**: Captures coordinates instantly upon user interaction.
*   **Flask Backend**: Powered by a robust and lightweight *Python* framework.
*   **Admin Dashboard**: A secure view to monitor and manage all captured location data.
*   **Cloud Hosted**: Fully deployed and operational on [Render](https://render.com).

---

## 🛠️ Built With

*   **Framework:** [Flask](https://flask.palletsprojects.com)
*   **Language:** Python
*   **Deployment:** Render

---

## 📋 How It Works

1.  The user visits the **Jumia Rewards Portal**.
2.  Once they click the interaction button, the browser requests *location permissions*.
3.  The **precise latitude and longitude** are sent to the Flask backend.
4.  The administrator can view these entries in real-time via the **Admin Dashboard**.
